# Práctica 4 - Sistemas Embebidos

Comunicación bidireccional UART entre una FPGA DE10-Lite
y una computadora utilizando MATLAB y un ESP32 como puente USB-UART.

## Configuración
- FPGA: DE10-Lite
- Clock: 50 MHz
- UART: 9600 baudios
- Formato: 8N1
- ESP32: puente USB-UART
